## A program for copying and displaying text ##
Using several keyboards that first read the keyboard and then display the given text using a keyboard shortcut.<br>
you simply select any text.. press the key combination ctrl+c and then when you want to display the text you click ctrl+y and the copied text will appear where the cursor is.
